# Canvito Studio

Create a graphic editor called Canvito, based on the provided image.

The interface must strictly follow this technical layout:

1 - Top bar (navbar): gradient background in neon violet/electric blue, cyberpunk style. On the left, "Arquivo", "Redimensionar", and "Editar" buttons; in the center, the name of the editable design and the design dimensions in pixels, and on the right, comment buttons in the form of a speech bubble and a large highlighted white button labeled "Exportar".

2 - Sidebar: gradient background in neon violet/electric blue, cyberpunk style. A narrow bar that, when a button is clicked, opens an expandable side panel next to it with the options for each category.

The sidebar should have the following buttons, from top to bottom: "Removedor de Objetos", "Elementos", "Texto", "Uploads", "Marcação", "Removedor de Fundo", "Backgrounds", "Editar", and "IA Mágica".

3 - Canvas: Center the image, using an icy gray tone to contrast with the white paper. The editing paper should initially be square, with dimensions of 1080 x 1080 px, centered with a soft box shadow. Below the paper, include the "Adicionar página" button.

4 - Bottom control bar - Include zoom controls (slider), page grid view, and full-screen button.
